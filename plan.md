
## Official website direction

VitalForge is presented as the official website for the desktop health companion, with the product promise at the center: making everyday health easier to understand and repeat. The content uses product language across the navigation, experience, technology, method, downloads, and promise sections.

The supplied VitalForge mark is used in the header, footer, favicon, Apple touch icon, and managed project logo metadata. The visual system remains nature-led and fitness-oriented, with a deeper product voice, stronger calls to action, and clearer download messaging for the Windows and macOS desktop applications.

Motion is an intentional part of the brand: Lenis provides smooth scrolling, GSAP/ScrollTrigger orchestrates staged reveals and scroll-linked parallax, and ambient orbit pulses, dashboard breathing, staggered capability entrances, magnetic CTAs, and pointer depth give the page a more authored motion-design feel. Touch devices and `prefers-reduced-motion` receive calmer behavior and no pointer-driven effects.

## Desktop distribution update

The site includes a responsive Material 3-inspired desktop download section with separate Windows and macOS cards. `public/downloads/vitalforge.exe` and `public/downloads/vitalforge.app.zip` are the stable platform download targets, with the macOS bundle source kept in `public/downloads/vitalforge.app/`.

The application repository now reports version 1.0.0, includes a verified Windows executable at `dist/VitalForge.exe`, and contains configured but not yet natively verified macOS and Linux packaging. The website therefore exposes the current Windows executable and labels macOS/Linux as pending native verification instead of presenting unverified artifacts as ready downloads.
